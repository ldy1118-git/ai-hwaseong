## 베이스라인 vs v1 주요 차이

### 1. is_expired 판정 (F2A-04) — 베이스라인의 유일한 중요 실패

| | baseline | v1 |
|---|---|---|
| apply_period.end | 2026-02-28 | 2026-02-28 |
| is_expired 판정 | **false** ← 실패 | **true** ← 정상 |

**원인**: 베이스라인은 시스템 프롬프트 없이 날짜 기준 없이 판단 → "미래인지 과거인지" 인식 불가.  
**v1 해결**: 시스템 프롬프트에 "오늘 날짜는 2026년 8월 15일" 명시 → 만료 여부 정확 판정.

---

### 2. Null 규율 — 양쪽 모두 통과하지만 품질 차이 존재

**F2A-02** (금융비용 지원 — summary 잘림):

| 필드 | baseline | v1 |
|---|---|---|
| `support_amount` | `"본문 내용 절단으로 인해 구체적인 지원 금액 및 환급 한도 미기재"` | `null` |
| `missing_info` | `["구체적인 지원 금액 및 이자 환급 비율", ...]` | `["support_amount"]` |

베이스라인은 null이어야 할 필드에 "왜 모르는지" 설명 텍스트를 채움. 이 값을 JSON으로 소비하는 매칭 엔진이 null 체크를 해도 문자열을 받게 되어 **타입 불일치** 발생.

**F2A-03** (마케팅 지원 — HTML 노이즈):

| 필드 | baseline | v1 |
|---|---|---|
| `support_amount` | `"공고문 내 미기재"` | `null` |
| `support_type` | `"마케팅 및 판로 지원"` (자유 텍스트) | `"판로"` (enum 스타일) |

## 케이스별 상세

### F2A-01 — 정상 입력 (법률·세무·노무 무료 상담)

**입력 공고**: `PBLN_000000000123334` — 소상공인 대상 전문가 1:1 무료 상담

**baseline 출력**
```json
{
  "one_line": "소상공인을 대상으로 법률, 세무, 노무 분야 전문가의 1:1 무료 상담(전화·서면)을 지원하는 사업입니다.",
  "support_type": "전문가 상담 및 자문 지원",
  "support_amount": "무료 상담 지원 (별도 현금 지급 없음)",
  "target_summary": "소상공인 누구나",
  "is_expired": false,
  "missing_info": ["구체적인 신청 방법 및 접수처", "신청 시 제출해야 하는 서류", "업체당 상담 횟수 제한"]
}
```

**v1 출력**
```json
{
  "one_line": "소상공인 대상 무료 법률·세무·노무 상담 지원",
  "support_type": "컨설팅",
  "support_amount": null,
  "target_summary": "소상공인 누구나",
  "is_expired": false,
  "missing_info": ["support_amount", "caution"]
}
```

**차이**: `support_amount`가 "무료"라는 사실은 같지만, baseline은 설명 텍스트로, v1은 null로 반환. `무료`는 금액이 아니므로 v1이 옳음.

## 특이사항

- **503 오류 반복**: gemini-3.6-flash 모델이 고부하 시 503 반환. 재시도 시 복구됨. 프로덕션 환경에서는 retry 로직 필요.
- **Free tier 제한**: 분당 5 requests. 테스트 스크립트를 순차 + 15초 딜레이로 운영. 병렬 실행 시 429 발생.
- **베이스라인 F2A-02 미탐**: `support_amount`에 구체적 숫자는 없지만 설명 텍스트를 채움. 현재 체크는 숫자 패턴만 검사해 PASS 처리. 더 엄격한 체크(null 여부)를 적용하면 baseline 3/5.
