# 이 서비스가 왜 필요한가 — 근거 자료

발표 1번 슬라이드용. 심사위원이 가장 먼저 묻는 "그래서 이게 왜 필요하냐"에 답하는 자료다.

숫자는 전부 출처를 달았다. **출처 없는 숫자는 발표에서 쓰지 않는다.**
반박당하면 그 뒤 내용을 아무도 안 듣는다.

---

## 한 문장

> 나랏돈은 역대 최대인데, 정작 소상공인은 **그런 게 있는 줄 몰라서** 못 받는다.

---

## 근거 1 — 돈은 충분하다 못해 역대 최대다

2026년 중소벤처기업부 소상공인 예산 **5.4조 원**, 7개 분야 26개 사업.

| 구분 | 규모 |
|---|---|
| 직접 지원사업 | 1조 3,410억 원 |
| 정책자금 | 3조 3,620억 원 |

출처: 중소벤처기업부 2026년 소상공인 지원사업 통합 공고

**말하는 법:** "돈이 없어서 못 받는 게 아닙니다."

---

## 근거 2 — 그런데 3.2%만 받는다. 이유 1위는 "몰라서"

중소기업중앙회가 소상공인 500개사를 조사한 결과다.

| 항목 | 수치 |
|---|---|
| 정부 지원사업 참여 경험 | **3.2%** |
| 참여 못 한 이유 1위 — "정책 자체를 알지 못했다" | **76.2%** |
| 참여해 본 사람의 만족도 | **87.5%** |

출처: 중소기업중앙회 소상공인 디지털 전환 실태조사 (2026, 500개사)

> **주의 — 발표에서 정확히 말할 것**
> 이 조사는 **디지털·AI 전환 관련** 지원사업에 한정된 수치다.
> "모든 지원사업 참여율이 3.2%"라고 하면 과장이고, 질문받으면 무너진다.
> **"디지털 전환 지원사업의 경우"** 라고 붙여서 말할 것.

**말하는 법:** "제도를 써본 사람 열에 아홉은 만족합니다. 문제는 열에 아홉이 존재 자체를 모른다는 겁니다."

이 세 숫자가 한 세트일 때 가장 강하다. 좋은 제도인데 → 몰라서 못 쓰고 → 쓴 사람은 만족한다. **정보 전달만 고치면 되는 문제**라는 뜻이기 때문이다.

## 근거 3 — 기다려줄 시간이 없다

| 항목 | 수치 |
|---|---|
| 창업 1년 생존율 | 77.0% |
| 3년 생존율 | 52.3% |
| **5년 생존율** | **40.2%** |
| 2025년 폐업 사업자 | 97만 6,000개 |
| 폐업 사유 — 매출 부진·수익성 악화 | 10명 중 7명 |
| 평균 창업비용 | 8,300만 원 (본인부담 5,900만 원) |

출처: 국세청 100대 생활업종 통계, 서울경제·한국경제 보도 (2025)

**말하는 법:** "10곳 중 6곳이 5년 안에 문을 닫습니다. 5,900만 원을 본인 돈으로 넣고 시작한 사람들입니다. 지원사업을 3개월 늦게 아는 것이 그 사람에게는 치명적입니다."

## 근거 4 — 정보가 구조적으로 흩어져 있다 (우리가 직접 조사한 것)

**이 항목이 제일 세다. 남의 통계가 아니라 우리가 이번에 직접 재서 나온 1차 자료다.**

기업마당 API 공고 1,539건과 화성시청 고시공고 9,467건을 실제로 수집·분석했다.

> **측정 기준일: 2026-08-15.**
> 기업마당 API는 실시간이라 숫자가 매일 바뀐다. 발표 당일 아침에
> `collect.py --coverage` 를 다시 돌려서 수치를 갱신할 것.

### 화성시청만 봐서는 못 찾는다

| | 건수 |
|---|---|
| 화성시가 직접 하는 소상공인 지원사업 (연간) | **3건** |
| 화성시 소상공인이 실제로 신청 가능한 공고 | **62건** |
| 그중 지금 접수 중 | **31건** |

화성시 전용으로 잡히는 공고는 4건인데, 그중 1건(여성 농업인 특수건강검진)은
농업인 대상이라 소상공인 공고가 아니다. 그래서 3건이다.

**20배 차이다.** 시청 홈페이지만 보는 소상공인은 신청할 수 있는 사업의 95%를 못 본다.
전국·경기도 대상 사업도 화성시 소상공인이 그대로 신청할 수 있기 때문이다.

### 공고를 찾아도 그다음이 막힌다

수집한 공고 25건을 분석한 결과다.

| 항목 | 수치 |
|---|---|
| **문의·접수를 소관기관이 아닌 곳에서 받는 공고** | **25건 전부 (100%)** |
| 신청 사이트가 별도로 있는 공고 | 22건 / **9개 사이트로 흩어짐** |
| 공고 1건당 행정용어 | 평균 3.8개 (최대 12개) |
| 공고 1건당 제출서류 | 평균 2.7종 (최대 11종) |
| 요구되는 서류 종류 | 19종 |
| 공고문 첨부가 기계로 읽히는 비율 | **13/31건 (42%)** — 나머지는 스캔 이미지·HWP |

**말하는 법:**
- "공고를 찾아도 끝이 아닙니다. 25건 전부, 문의처가 공고를 낸 기관이 아닌 다른 곳입니다. 시청에 전화하면 '저희 소관 아닙니다'라는 답을 듣습니다."
- "신청은 9개 사이트에 흩어져 있습니다."
- "공고문의 58%는 스캔한 이미지라 검색조차 안 됩니다. 사람이 눈으로 읽는 수밖에 없습니다."

마지막 항목은 특히 좋다. **"정보가 없는 게 아니라, 있는데 읽을 수가 없다"** 는 걸 숫자로 보여준다.

## 그래서 우리 서비스가 하는 일

| 문제 | 근거 | 우리 기능 |
|---|---|---|
| 있는 줄 모른다 | 76.2% "몰라서" | 조건 입력 → 신청 가능한 공고 자동 매칭 |
| 시청만 봐서는 못 찾는다 | 3건 vs 62건 | 기업마당·화성시청 통합 수집 |
| 공고문이 안 읽힌다 | 1건당 용어 3.8개 | 행정용어 사전 31개 + 서류 26종 자동 설명 |
| 어디에 내는지 모른다 | 접수처 불일치 100% | 접수처·신청 URL·문의처를 결과에 같이 표시 |
| 서류를 어떻게 떼는지 모른다 | 19종, 최대 11종 | 서류별 발급처·비용·소요시간 안내 |

### 1장 — 문제

```
        5.4조 원                    3.2%

              못 받은 이유 1위

           "그런 게 있는 줄 몰랐다"
                  76.2%
```

### 2장 — 우리가 직접 재봤습니다

```
   화성시청 홈페이지에서 찾을 수 있는 공고        3건
   화성시 소상공인이 신청할 수 있는 공고         62건

                    20배
```

### 3장 — 찾아도 못 낸다

```
   접수처가 공고 낸 기관과 다른 비율      100%
   신청 사이트                         9곳에 흩어짐
   공고문이 기계로 읽히는 비율            42%
```

숫자를 크게, 설명은 말로. 슬라이드에 문장을 넣으면 아무도 안 읽는다.

```bash
python3 policy_data/collect.py --coverage    # 3건 vs 62건 (API 실시간)
python3 policy_data/extract.py --review      # 서류·접수처
python3 policy_data/terms.py --stats         # 용어 사전 규모

```

접수처·사이트·서류 종수는 `policy_data/notices/` 의 JSON 25건을 직접 센 것이다.
용어 개수는 첨부 공고문 원문이 있는 10건은 원문에서, 나머지 15건은 API 요약에서
`terms.py` 의 `find_terms()` 로 셌다.

## 쓰면 안 되는 것

- **"3.2%만 지원받는다"** — 디지털 전환 분야 한정 수치다. 분야를 반드시 밝힐 것
- 출처를 못 찾은 숫자. 그럴듯해 보여도 빼는 게 낫다
- 화성시 사업체 144,173개를 "소상공인 수"로 쓰는 것 — 전체 사업체 수이고
  소상공인만 센 게 아니다. 조사 대상 예측치라 확정치도 아니다
