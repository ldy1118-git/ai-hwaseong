## 2. 발표에 쓸 새 근거

시청 홈페이지에서 '소상공인'을 검색하면:

```
전체 고시공고               9,458건
'소상공인' 검색 결과            67건
  ├ 대형마트 입점 예고         50건   ← 지원사업 아님
  └ 실제 지원사업              17건
```

**검색 결과의 75%가 대형마트 입점 예고다.** 담당부서가 소상공인과라 걸릴 뿐이다.

더 센 건 이거다. 2021~2024년 지원사업은 제목이 이렇다.

```
2022년 화성시 중소기업 운전자금 지원계획 공고
2022년 화성시 중소기업 특례보증 지원계획 공고
```

**소상공인이 신청 대상인데 제목이 「중소기업」이라 검색에 안 잡힌다.**
이런 누락이 그 기간에만 10건 확인됐다.

> **말하는 법:** "시청에서 '소상공인'을 검색하면 67건이 나오는데 50건이
> 대형마트 입점 예고입니다. 진짜 지원사업은 17건이고, 그마저도 제목이
> '중소기업 운전자금'이면 아예 빠집니다. 키워드로는 못 찾는 구조입니다."

*주의: 17건은 제목만 보고 센 하한값이다. 질문받으면 그대로 밝힐 것.*

## 3. 서희에게 — 프론트 관련

작업 잘 봤다. 아래는 타이밍이 어긋나서 생긴 것들이라 잘못한 게 아니다.
(서희 푸시 8/15 18:19, 내 CORS 커밋 8/15 23:48)

### ① 가짜 공고를 부르고 있다 — 이것만 급하다

`project/src/utils/api.js`

```js
notices_folder: 'notices',   // ← 이 줄 지우면 된다
```

`'notices'`는 `backend/notices/` = 형식 참고용 **가짜 19건**으로 풀린다.
실제 공고 25건이 이미 기본값이라 **이 한 줄만 지우면** 진짜 공고가 뜬다.
지금 이대로 시연하면 존재하지 않는 공고가 화면에 나온다.

### ② `dev_server.py`는 이제 필요 없다
CORS를 본체(`backend/matching.py`)에 넣었다. 게다가 그 파일이 보는 경로가
`ai-hwaseong/matching` 인데 폴더 이름을 `backend/`로 바꿔서 지금은 안 돌아간다.
→ 파일 지우고 `./scripts/run_server.sh 8000` 쓰면 된다.

### ③ `terms.json` 사본이 원본과 갈라졌다
`project/src/data/terms.json`, `project/scripts/fixtures/f2a/terms.json`
→ `GET /api/terms` 로 받아 쓰면 사본을 안 들고 있어도 된다.

### ④ 폴더가 두 벌 (서희가 정할 것)
| 새로 올라온 것 | 기존 |
|---|---|
| `project/` | `frontend/` |
| `project/scripts/` | `llm/` (같은 파일명 22개) |

어느 쪽을 남길지 서희가 정해줘. 내가 손대면 충돌난다.
