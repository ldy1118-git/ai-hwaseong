# 2차 발표 — 시연 순서

영상이 빨라서 **그 자리에서 직접 보여준다.** 덱은 이미 냈으므로 슬라이드는
그대로 두고, 영상 자리에 사람이 들어간다.

    11장 → 12장 을 연달아 넘긴다        30초   말로만
    앱으로 들어간다 · 한 번만          3분 30초
    덱으로 돌아온다

12장의 「▶ 시연 영상 ② 2분 · 여기서 재생합니다」는 **그냥 지나간다.**
11장에서 「영상 대신 직접 보여드리겠습니다」라고 한 번 말해두면 된다.

---

## 왜 한 번만 들어가나

예비창업자와 사업자는 **같은 브라우저에 같이 못 있는다.** 둘 다
`localStorage` 의 같은 자리(`mars-fit-profile`)를 쓴다.

그래서 **시크릿 창을 미리 하나 띄워둔다.** 저장 공간이 따로라 두 프로필이
공존한다. 시연 중에는 창만 바꾼다 — 1초다.

    일반 창    예비창업자 · 카페 · 30세
    시크릿 창   사업자 · 음식점 · 24개월 운영

이걸 안 하면 시연 도중에 온보딩 화면으로 돌아가 프로필을 갈아야 하고,
그 10초가 화면에 그대로 나온다.

---

## 시연 대본

말은 **초안이다.** 그대로 읽지 말고 편한 말로 바꿀 것.

### 여는 말 (덱 11장·12장 위에서, 30초)

> 지금부터는 영상 대신 직접 보여드리겠습니다.
> 같은 앱인데 두 분에게 다르게 열립니다.
> 아직 가게가 없는 분께는 **어디에 낼까**를,
> 이미 하고 계신 분께는 **언제까지 뭘 해야 하나**를 답합니다.

여기서 앱으로 넘어간다.

|---|---|---|---|

| 0:15 | 홈 | 1위 카드 「매칭이유」 | 왜 맞는지도 같이 보여드립니다. 점수만 던지지 않습니다. |
| 0:25 | 공고 상세 | 원문 쪽을 한 번 훑고 | 공고문 원문입니다. 이걸 끝까지 읽으실 사장님은 없습니다. |
| 0:40 | 공고 상세 | 정리된 쪽 | 같은 공고를 정리한 것입니다. 누가, 얼마를, 언제까지. |
| 0:50 | 공고 상세 | 「소상공인」 같은 낱말 탭 | 모르는 낱말은 눌러서 바로 뜻을 봅니다. 43개를 미리 풀어뒀습니다. |

## 발표 직전에 할 것

### 30분 전

```
python3 scripts/preflight.py
```

**[6] 외부 서버**가 초록불이어야 OCR 과 지도가 산다. ❌ 면 아래
「끊겼을 때」로.

### 10분 전 — 창 두 개를 만든다

**일반 창** — 예비창업자

1. `https://ai-hwaseong-ten.vercel.app` 열기
2. 온보딩 어느 화면에서든 아래 **「시연용 · 예비창업자」**(화성시 · 카페 · 30세)
3. 홈이 뜨면 **공고 상세를 한 번 열어둔다** — LLM 요약이 처음 한 번은 몇 초 걸린다
4. **내 매장(지도)도 한 번 열어둔다** — 지도 데이터가 764KB 라 처음이 느리다
5. 홈으로 돌아와 둔다

**시크릿 창** — 사업자

1. 시크릿 창에서 같은 주소
2. **「시연용 · 운영중 사장님」**(화성시 · 음식점 · 24개월)
3. 일정 탭 · 서류 준비를 한 번씩 열어둔다
4. **온보딩 등록증 화면으로 돌려놓는다** — 여기서 시작한다

> 매칭 결과는 3분만 캐시된다. 10분 전에 열어둔 것은 시연 때 다시 받는다.
> 그래도 **LLM 요약과 지도 데이터는 남아 있어서** 체감이 다르다.

### 5분 전 — 폰

- 사업자등록증 사진을 **갤러리 맨 앞**에 둔다
- 카카오톡을 열어 **「나와의 채팅」**을 띄워둔다
- 알림·전화 무음

### 카톡을 그 자리에서 보내려면

```
python3 scripts/notify_kakao.py --demo --user <내 id>
```

제일 잘 맞는 1건을 즉시 보낸다. **보낸 기록을 안 남기므로 몇 번이든
다시 된다** — 리허설에서 써버려도 본 무대에서 또 온다.

`~/bin/mars-kakao.sh` 는 그냥 부르면 정해둔 시각을 지키므로 시연에는 못 쓴다.

## 끊겼을 때

| 무엇이 | 어떻게 되나 | 무엇을 한다 |
|---|---|---|
| OCR 서버가 죽음 | 온보딩이 **알아서 직접 입력으로 간다.** 사진 화면이 아예 안 나온다 | 그대로 진행. 「사진으로도 되는데 지금은 직접 입력으로 보여드리겠습니다」 |
| 지도가 안 뜸 | 상권분석이 통째로 503 | ①의 마지막 칸을 빼고 넘어간다. 덱 6~8장에 숫자가 다 있다 |
| LLM 요약이 느림 | 몇 초 도는 중 | 그 사이 원문 쪽을 설명한다. 어차피 그게 대비다 |
| 카톡이 안 옴 | 발송 실패 | 덱 7장에 **실제로 온 알림 스크린샷**이 있다. 그걸 가리킨다 |
| 와이파이가 끊김 | 전부 정지 | 폰 핫스팟. 미리 붙여보고 올 것 |
| 창이 헷갈림 | 프로필이 섞여 보임 | 시크릿 창은 주소창 색이 다르다. 그걸로 구분 |

**아무것도 안 될 때** — 덱 4·6·7·9장에 화면 사진이 전부 있다. 시연을
접고 그 장으로 돌아가서 말로 한다. 「지금 연결이 안 되어 사진으로
보여드리겠습니다」 한마디면 된다.

## 시간이 모자라면 자르는 순서

3분 30초를 넘길 것 같으면 **뒤에서부터** 자른다.

```
1순위로 자른다   ① 의 「매칭이유」        15초   점수만 말하고 넘어간다
2순위            ② 의 서류 「한 줄 펴기」  15초   목록만 보여주고 신청 완료로
3순위            ① 의 유동인구 칸         15초   덱 8장에 계산식이 있다
```

**끝까지 남겨야 하는 것 둘**

- **OCR 사진 → 자동 입력** — 눈으로 보이는 것 중 제일 강하다
- **카카오톡 도착** — 앱 밖으로 나가는 유일한 기능이다. 「진짜 되는구나」가
  여기서 나온다

---

## 장비

노트북 하나 · 폰 하나.

**폰 미러링은 안 한다.** 카톡 하나 때문에 장비를 하나 더 걸면 그게
제일 잘 깨진다. 카톡은 **폰을 들어서 보여준다** — 심사위원 다섯 분이면
그게 더 자연스럽고, 「이게 지금 온 겁니다」가 더 잘 전해진다.

브라우저는 창 두 개만. 탭을 여러 개 두지 말 것 — 바꿀 때 헷갈린다.
