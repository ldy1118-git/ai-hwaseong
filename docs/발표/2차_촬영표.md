# 2차 시연 영상 촬영표

두 편을 따로 찍는다. **영상 ① 예비창업자 1:30 + 영상 ② 사업자 2:00 = 3:30**

한 덩어리로 이어 붙이지 않는다. 발표 중에 **6장 뒤에 ①, 7장 뒤에 ②** 를 각각 튼다.

| | 분량 | 사람 | 슬라이드 |
|---|---|---|---|
| **영상 ①** | 1:30 | 예비창업 · 카페 · 화성시 · 30세 | 6장 「어디에 낼까」 뒤 |
| **영상 ②** | 2:00 | 운영중 · 음식점 · 24개월 · 직원 있음 | 7장 「언제까지 뭘 하나」 뒤 |

무음으로 찍고 **자막을 얹는다.** 지난 발표에서 「목소리가 작아 기능을 못 들었다」는
말이 나왔다. 영상을 늘려도 안 들리는 건 똑같다. 자막은 발표장 스피커와 무관하다.

---

## 찍기 전에

### 서버가 다 떠 있어야 한다

    python3 scripts/preflight.py

**[6] 외부 서버가 초록불인지 반드시 볼 것.** pjrx.kr 이 꺼져 있으면
상권분석이 빈 화면으로 뜨고 사업자등록증 사진도 안 읽힌다. 둘 다 영상의
주인공이라 그날 촬영이 통째로 날아간다.

    ✅ OCR 사진        ← 영상 ② 0:00–0:24 가 여기에 달려 있다
    ✅ 상권분석         ← 영상 ① 0:44–1:30 이 전부 여기다
    ✅ 유동인구 중계

### 화면

- 1920×1080 · 30fps · 브라우저 **125%** (이 배율부터 두 단 배치가 나온다)
- **주소창은 보이게 둔다.** `ai-hwaseong-ten.vercel.app` 이 실제로 떠 있다는 증거다.
  전체화면(F11)은 쓰지 않는다
- 북마크바 숨김, 확장 아이콘 정리, 탭 하나만
- 마우스는 천천히. 누를 것 위에서 한 박자 멈췄다가 누른다

### 예열 한 바퀴

촬영 30초 전에 홈 → 공고 상세 → 서류까지 한 번 돌린다. 안 하면 첫 매칭이
몇 초 멈추고, **AI 한 줄 요약이 뒤늦게 도착하면서 화면이 한 번 튄다.**

상권분석은 따로 예열한다 — 지도에 핀을 한 번 옮겨서 `/api/commercial` 을
깨워둔다. 서버가 CSV 를 처음 읽을 때 몇 초 걸린다.

### 시작 위치

- **영상 ①** 내 정보 → 탈퇴 → 카카오로 다시 들어와 **온보딩 첫 질문에서 대기.**
  랜딩과 카카오 로그인은 찍지 않는다
- **영상 ②** 마찬가지로 초기화하되, **사업자등록증 사진 파일을 미리 바탕화면에** 둔다.
  파일 탐색기에서 헤매는 장면이 들어가면 안 된다

## 영상 ① — 예비창업자 (1:30)

아직 가게가 없는 사람이 **어디에 낼지**를 정하는 흐름. 뒤 절반이 상권분석이다.

| 시각 | 화면 | 무엇을 한다 | 자막 |
|---|---|---|---|
| `0:00`–`0:06` | 온보딩 Q1 | 「지금 어떤 상황이세요?」 → **예비창업자** | 조건을 몇 번 누르면 |
| `0:06`–`0:11` | 온보딩 | 업종 → **요리·음식** → **카페** | |
| `0:11`–`0:15` | 온보딩 | 지역 → **화성시**, 나이 → **30** | |
| `0:15`–`0:20` | 온보딩 | 남은 문답을 연속으로 누르고 완료 | |
| `0:20`–`0:26` | 홈 | 도착. **「지금 신청할 수 있어요 11건」에서 3초 정지** | 신청할 수 있는 것만 남습니다 |
| `0:26`–`0:32` | 홈 | 오른쪽 공고 목록을 천천히 스크롤. **1위 점수가 보이게** | |
| `0:32`–`0:36` | 홈 | 첫 카드의 **「매칭이유 ▼」** 클릭 → 조건 판정이 펼쳐진다 | 왜 되는지도 같이 보여줍니다 |
| `0:36`–`0:40` | 홈 → 공고 | **「자세히 →」** 클릭 | |
| `0:40`–`0:46` | 공고 상세 | 본문을 천천히 스크롤 | |
| `0:46`–`0:52` | 공고 상세 | **점선 밑줄 친 행정용어**에 커서를 올린다 → 뜻풀이가 뜨면 **3초 정지** | 모르는 낱말은 눌러서 바로 |
| `0:52`–`0:56` | → 내 매장 | 상단 **「내 매장」** 클릭 → 상권분석 인트로 | 자리는 어떻게 고를까요 |
| `0:56`–`1:04` | 상권분석 ① | 「어디서 창업하고 싶으세요?」 — **주소를 검색하거나 핀을 끈다** | ① 위치를 찍고 |
| `1:04`–`1:16` | 상권분석 ② | 「범위를 설정해보세요」 — **슬라이더를 천천히 끈다.**<br>**숫자가 같이 움직이는 것이 이 영상에서 제일 중요하다.** 왕복 한 번 | ② 반경을 끌면 숫자가 같이 움직입니다 |
| `1:16`–`1:24` | 상권분석 ③ | 「이 위치의 상권은 어때요?」 — 지표 넷과 **경쟁 현황**에서 정지 | ③ 유동인구 · 카드매출 · 업종 분포 · 경쟁 현황 |
| `1:24`–`1:30` | 상권분석 ④ | 「마이다의 종합 한마디」가 뜨는 것까지 | ④ 마이다가 읽어서 정리해줍니다 |

**②를 넉넉히 잡은 이유** — 슬라이더를 끌 때 음식점·카페 수가 실시간으로 바뀐다.
말로 「실제 데이터입니다」라고 하는 것보다 이 12초가 세다. 왕복 한 번은 꼭 넣을 것.

## 영상 ② — 사업자 (2:00)

이미 하고 있는 사장님이 **언제까지 뭘 해야 하나**를 확인하고, 실제로 신청까지 가는 흐름.

| 시각 | 화면 | 무엇을 한다 | 자막 |
|---|---|---|---|
| `0:00`–`0:06` | 온보딩 Q1 | 「지금 어떤 상황이세요?」 → **운영중** | 이미 하고 계신 사장님이라면 |
| `0:06`–`0:12` | 온보딩 | **사업자등록증 사진**을 올린다 (드래그 또는 선택) | 등록증 사진 한 장이면 |
| `0:12`–`0:22` | 온보딩 | 읽는 중 표시 → **과세유형·개업일·업종이 채워지는 화면에서 3초 정지** | 과세유형 · 개업일 · 업종이 채워집니다 |
| `0:22`–`0:30` | 온보딩 | **직원 있음** → **원천세 매월** 을 누르고 완료 | |
| `0:30`–`0:38` | 내 매장 | 도착. **「다음 세무일정」 D-day 카드에서 3초 정지** | 다음 신고까지 며칠 남았는지 |
| `0:38`–`0:50` | 내 매장 | **「앞으로 챙길 신고」** 를 천천히 스크롤.<br>직원이 있어서 늘어난 항목들이 보이게 | 직원이 있으면 챙길 게 넷 더 있습니다 |
| `0:50`–`0:58` | 내 매장 | 오른쪽 **「내 지원사업」** — 신청가능 건수와 1위에서 정지 | 받을 수 있는 것도 같이 |
| `0:58`–`1:04` | → 공고 | 공고 하나를 눌러 상세로 | |
| `1:04`–`1:10` | 공고 상세 | 아래로 스크롤 → **「서류 준비하기」** 클릭 | |
| `1:10`–`1:24` | 서류준비 창 | 옆에서 열린다. 서류 하나를 눌러 **발급 절차·수수료·소요시간**에서 정지 | 어디서 어떻게 떼는지까지 |
| `1:24`–`1:32` | 서류준비 창 | 체크를 두어 개 누른다 — **진행률이 차오르는 것**이 보이게 | 어디까지 했는지 남습니다 |
| `1:32`–`1:40` | 서류준비 창 | **「신청 완료」** 를 누른다 → 마이다가 축하하는 화면에서 정지 | |
| `1:40`–`1:46` | 공고 | **★** 를 눌러 관심공고에 담는다 | 담아두면 |
| `1:46`–`1:54` | → 일정 | 상단 **「일정」** → 달력에서 그 공고 마감일이 찍힌 것을 보여준다 | 달력에서 다시 만납니다 |
| `1:54`–`2:00` | **폰 화면** | 카카오톡 「나와의 채팅」에 온 알림 | 새 공고와 신고기한은 새벽에 먼저 갑니다 |

### 카톡 장면은 따로 찍는다

브라우저 화면이 아니라 **폰을 찍어서 끼워 넣는다.** 새 공고를 기다릴 수 없으므로
시연용으로 그 자리에서 한 통 보낸다.

    python3 scripts/notify_kakao.py --demo --user <아이디>

**보낸 기록을 남기지 않으므로 몇 번이든 다시 된다.** 리허설에서 써도 괜찮다.

## 찍기 전에 팀에 확인할 것

- **상권분석 화면에 출처 줄이 없다.** UI 개편에서 빠졌다. 영상 ① 1:16~1:24 에
  음식점·카페 수와 카드매출이 그대로 나오는데 어디서 온 값인지 화면에 안 적혀 있다.
  「이 숫자 어디서 났어요」가 나오면 화면으로 답이 안 된다 (성현)
- **카드매출은 2020년 3월 데이터인데 화면에 날짜가 없다.** 같은 자리다 (성현)
- `cheer.png` 는 올라왔다. 서류준비 창 「신청 완료」에 **응원 포즈가 나온다** (해결됨)

## 편집

- 컷 사이는 자르기만 한다. 전환 효과를 넣지 않는다 — 3분 30초에 효과가 끼면 길어 보인다
- 로딩으로 멈춘 구간은 잘라낸다. 단, **OCR 이 읽는 2~3초는 남긴다** — 진짜로
  읽고 있다는 표시다
- 자막은 화면 아래 가운데. 표의 자막 칸이 그대로 들어간다
- 배경음악은 넣지 않는다. 발표장에서 말과 겹친다
