────────────────────────────────────────
1. 프로젝트 개요
────────────────────────────────────────

서비스명: 화성 경영동행 AI
목적: 화성시 소상공인의 정보 비대칭·디지털 리터러시 격차 해소
핵심 차별점:
  - 사용자가 물어보지 않아도 먼저 알려주는 "푸시형" 구조
  - 화성시 행정동(동탄·향남·남양읍 등) 단위 하이퍼로컬 데이터
  - 서류 체크리스트 기반 신청 완료까지 "동행" 구조
  - 예비창업자(창업 전 단계) 포함 지원
  - 경쟁 서비스(소상공인365, 캐시노트)와 달리 화성시 특화

2. 기술 스택
────────────────────────────────────────

[프론트엔드 - 현재 구현됨]
  - React 18 + Vite 6
  - Tailwind CSS 3
  - React Router DOM 6 (HashRouter - JupyterHub 프록시 환경 대응)
  - Lucide React (아이콘)
  - @google/generative-ai 0.24.1 (Gemini SDK)

[LLM]
  - Google Gemini API (gemini-flash-latest 모델)
  - API 키: aistudio.google.com에서 발급 (AQ. 형식)
  - 키 저장 위치: /home/jovyan/work/project/.env (VITE_GEMINI_API_KEY)

[백엔드 - 미구현, 2차 계획]
  - FastAPI + PostgreSQL (예정)
  - RAG: Chroma 벡터DB + BGE-M3 임베딩 (예정)
  - 외부 API: 기업마당 Open API, 소상공인시장진흥공단 상권정보시스템 (예정)

[서빙 환경]
  - JupyterHub (ahnbi3.suwon.ac.kr:5001)
  - 접속 URL: https://ahnbi3.suwon.ac.kr:5001/user/22016084/proxy/3002/
  - 서빙 방식: npm run build → dist/ 폴더를 Python http.server로 정적 서빙
  - 포트: 3002 (python3 -m http.server 3002 --directory dist)
  - 주의: Vite 개발 서버(npm run dev)는 JupyterHub 프록시와 충돌하여 사용 불가
    → 코드 수정 후 반드시 npm run build + 서버 재시작 필요

3. 구현된 화면 (총 7개 페이지)
────────────────────────────────────────

[1] 랜딩 페이지 (/)
  - 상단 네비게이션 바 (로고, 서비스 구조도, 먼저 둘러보기, 시작하기 버튼)
  - 풀와이드 히어로 섹션 (그라디언트 배경)
  - 주요 기능 4열 소개 카드
  - 예비창업자 업종 비교 섹션 (최대 3개 선택, 평균매출/경쟁강도/지원사업 수 비교)

[2] 온보딩 (/onboarding)
  - 3단계: 창업 유형 선택 → 정보 입력(사업장 주소, 업종) → 완료
  - 모바일/웹 공용 (좌측 사이드바 숨김)

[3] 대시보드 (/dashboard)
  - 상단 인사 헤더 + 알림 아이콘
  - 긴급 배너 (D-5 이내 항목 있을 경우 표시)
  - 빠른 메뉴 4개 (세무일정, 지원사업, 상권보기, 매출진단-2차예정)
  - 세무일정 + 지원사업 2열 카드 목록
  - 상권 변화 3열 인사이트 카드

[4] 세무 신고 일정 (/tax)
  - 마스터-디테일 레이아웃 (좌측 목록 / 우측 상세)
  - 마감일 D-day 배지 (긴급/주의/일반)
  - 우측 패널: 서류 체크리스트 (클릭 시 완료 처리)
  - 홈택스 신고 바로가기 버튼

[5] 지원사업 찾기 (/support)
  - 마스터-디테일 레이아웃
  - 카테고리 필터 (전체/자금/디지털/지역/창업)
  - 매칭도 퍼센트 표시 (업종·지역 기반)
  - 우측 패널: 4단계 신청 동행 (자격확인 → 서류준비 → 신청제출 → 결과대기)
  - 지원금액, 마감 D-day, 매칭도 요약 카드

[6] 상권 변화 보기 (/district)
  - 3열 레이아웃 (좌측 지역선택+지표 / 우측 트렌드+차트+알림)
  - 지역별 트렌드 뱃지 (활성화/주의/보합)
  - 최근 6개월 방문객 추이 바 차트
  - 최근 변화 알림 카드 2열

[7] 서비스 구조도 (/map)
  - 사용자 플로우 3단계 시각화
  - 핵심 기능 4종 설명
  - 2차 예정 기능 목록

[공통 컴포넌트]
  - Sidebar: 좌측 고정 네비게이션 (240px), 대시보드·세무·지원사업·상권 메뉴
  - Chatbot (FAB): 우측 하단 고정 버튼 → 클릭 시 우측 슬라이드 패널 (384px)
    · 온보딩 화면에서만 숨김, 나머지 전 화면에서 표시
    · Gemini API 멀티턴 대화 연동
    · 시스템 프롬프트: 화성시 소상공인 전담 상담사 역할 부여
    · 빠른 질문 버튼 4개 (부가세, 지원사업 서류, 동탄 상권, 사업자등록)

4. 데이터 현황
────────────────────────────────────────

현재 모든 데이터는 목업(mockData.js)으로 하드코딩되어 있음.
실제 API 연동은 2차 개발 단계 예정.

[세무 일정 - 3건]
  - 부가가치세 신고·납부 (D-5, 긴급)
  - 종합소득세 중간예납 (D-42)
  - 4대보험 월별 납부 (D-10)

[지원사업 - 4건]
  - 화성산업진흥원 소상공인 경영안정자금 (최대 3,000만원, 매칭 95%)
  - 소상공인 디지털 전환 지원사업 (최대 200만원, 매칭 88%)
  - 동탄 상권 활성화 지원금 (최대 50만원, 매칭 82%)
  - 청년 창업 패키지 예비창업자 (최대 1억원, 매칭 70%)

[상권 인사이트 - 3건]
  - 동탄2신도시 음식점 방문객 +12% (증가)
  - 향남읍 소매업 매출 -8% (주의)
  - 남양읍 카페·디저트 매출 +6% (증가)

[업종 비교 데이터 - 6개 업종]
  음식점, 카페·음료, 소매업, 미용·뷰티, 교육·학원, 생활서비스
  (각각 평균 매출, 경쟁강도, 지원사업 수 포함)

[화성시 지역 데이터]
  동탄1~8동, 향남읍, 남양읍, 봉담읍, 우정읍, 장안면 등 20개 행정구역
